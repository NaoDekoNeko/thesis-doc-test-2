# Software Architecture

Este portal documenta los principios, patrones y decisiones de arquitectura de software del proyecto. Cubre desde los fundamentos de microservicios hasta las decisiones concretas registradas como ADRs.

## Áreas documentadas

| Área | Descripción |
|---|---|
| **Microservicios** | Fundamentos, descomposición y comunicación entre servicios |
| **APIs** | Diseño REST, versionamiento y contratos |
| **Patrones** | SOLID, patrones de diseño GoF y patrones de resiliencia |
| **ADRs** | Architecture Decision Records del proyecto |

## Relación con plataforma

La arquitectura de software define *qué* se construye. Las herramientas de plataforma documentadas en [Platform Engineering Docs](http://8.233.204.126/thesis-doc-test-1/) definen *cómo* se despliega y opera.

Por ejemplo, este portal describe la arquitectura de microservicios con servicios independientes. El portal de plataforma describe los pipelines CI/CD que permiten desplegar cada servicio de forma autónoma.

## Principios guía

- **Alta cohesión, bajo acoplamiento**: cada servicio tiene una responsabilidad única y bien definida.
- **Design for failure**: los servicios asumen que sus dependencias pueden fallar.
- **API-first**: los contratos de API se definen antes de implementar.
- **Decisiones explícitas**: toda decisión arquitectural significativa queda registrada como ADR.
